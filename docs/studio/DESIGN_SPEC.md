# Eyes Studio — UI design spec (round 2)

Round 1 was reviewed by four critics (science 5, interaction 6, visual 6, buildability 5; all
REVISE). This spec is the round-2 contract. **All numbers come from FIXTURE.md / fixture.json**
(generated by make_fixture.py). Never invent a count, a mean, a time estimate, a memory budget
or a hash; if a value is unknown at that moment, show the honest state ("counting…").

## 1. Product thesis (unchanged)
"Result → comparison → gaze → fixation → source record, and back." Measured quantity:
matched-minus-control spatial similarity: per query q and scale σ, M = cosine(map q, map matched
reference); B = mean cosine to every eligible control; D = M − B. Keep M, every control score, B
and D. It measures spatial correspondence, not sequential replay. D mixes item-specific
reinstatement with shared item-driven salience and residual centre bias; say so wherever D is the
headline. No inferential statistics in the MVP.

## 2. Perspectives (app-owned; one scaladock Dock per perspective in a StackPane)
Data ⌘1 · Explore ⌘2 · Analysis ⌘3 · Compare ⌘4 · Figures ⌘5
- Data: sources, column mapping, trial identity, geometry, admission.
- Explore: look at trials, fixations, time, source records. View-only.
- Analysis: the recipe/draft, resolved design, preflight, run. The only place that edits
  science (plus Data geometry/admission, which make a new DATASET revision).
- Compare: results. Two layouts in one perspective, chosen by the trail depth: Summary
  (study → participants) and Query (query → pair → maps). "Summary" crumb shows the summary
  layout; any deeper crumb shows the query layout.
- Figures: figure composer and export.
Why separate Docks: `Dock.load` disposes panes missing from a layout, so switching one Dock would
destroy views. A studio pane registry provides singletons ("one Query panel") and floating
windows of an inactive perspective are hidden.

## 3. Shell (identical on every board; copy from project/Main.dc.html)
Top → bottom (1440 wide):

   standard traffic lights #FF5F57 #FEBC2E #28C840, centred 12px "memory-study.eyes".
2. App bar 44px: eye-aperture mark + "Eyes Studio" wordmark; project chip; perspective
   segmented control (5 real buttons, shortcut hints); right: Jobs chip. Jobs chip states:
   idle "No jobs"; running "Run 8 · Comparing · 21,400 / 35,876 pairs" with a thin progress bar
   and an inline Cancel button; failed "Run 8 failed · 2 diagnostics".
3. Context strip 32px (every perspective): back / forward buttons (⌘[ ⌘]), the TRAIL (live
   crumb buttons, current crumb in ink 600), spacer, then FRESHNESS: one badge "Analysis rev 4 ·
   run 7 · data r3 · current" (teal dot) and, when a draft exists, a dashed chip "Draft rev 5 ·
   1 change · 1 blocker" that opens Analysis.
   Trail grammar: Study (reporting spec) › group › participant › query › pair › map ›
   fixation › record. e.g. "Summary · by retrieval response › Remembered › P17 › ret_07 ·
   beach-042 › pair ret_07 × enc_03 › fixation 6 › fixations.csv record 7,214". Fixation and
   record crumbs cross into Explore; the trail survives the switch.
4. Draft banner 30px, dock-wide, ONLY in Compare/Figures when a draft differs from the shown
   revision: dashed ink outline, "Showing run 7 (analysis rev 4). Draft rev 5 adds σ 8° — not
   run yet." [Review in Analysis] [Discard draft].
5. Dock area (scaladock): 1px hairline splitters, 28px tab headers, focused group's selected
   tab has a 2px accent top rule. Every perspective has a navigator group on the left (it can be
   minimized to a strip). Every plot pane has a sibling "Table" tab (keyboard equivalent).
6. Status bar 24px, fixed grammar: [● Selected: path] · [context hint] · [job + Cancel] ·
   [Saved 10:24]. Always all four slots (use "No jobs" when idle).

## 5. Roles: hue + shape + lightness (never hue alone)
Query = filled circle, --query (dark violet). Matched reference = diamond, --match (mid blue).
Control = hollow circle, --control (light amber); control text uses --control-text.
Roles exist only in Analysis/Compare/Figures. In Explore, fixations are neutral:
fill rgba(28,30,33,.35) (dark: rgba(236,234,229,.35)) with a 1.5px #FFFFFF halo.
D has no hue: ink, sign shown by position relative to a zero rule. Groups (Remembered /
Forgotten): solid ink vs dashed --ink-3, plus labels.

## 6. Maps and plots
Mass-map ramp (sequential, opaque per cell, one global opacity): #F9D9EA → #E58FB9 → #B83F86 →
#6B0F4F, plus isolines at 50% and 90% of mass (1px, ink @.6 on light stage, #FFFFFF @.8 on dark).
Maps are drawn on the --stage surround. Label the map units: "fixation duration mass per cell".
Difference maps only: diverging BlueRust #2E5A9C ← neutral → #B4442F, zero pinned.
Scale ladder (Compare): per scale row: control dots (hollow, 9px, beeswarm dodge ±4px),
B tick (3px full height, --control), M diamond (--match), and a 4px ink bar from B to M = D.
Log-spaced scale axes (0.5,1,2,4,8°). Journal figures: Plex Sans 7pt axes, panel letters 8pt
600; D on its own "Δ cosine" axis with a zero rule; serif only in methods prose.
Missing ≠ zero: missing values drawn as a dashed empty marker with "no value".

## 8. Three (four) kinds of change — same tags everywhere
"Dataset · re-admit" (column mapping, geometry, admission → new dataset revision, marks runs
stale) · "Analysis · rerun" (draft → Save & run) · "Reporting · no rerun" · "View only".

## 9. Science rules that must be visible
- Analysis window = image frame 1024×768 inside the 1920×1080 screen. Gaze outside the window is
  excluded from the map and REPORTED: per trial "outside window: 2 of 12 fixations · 9% of
  duration" (Inspector, Pairs table); a Reporting filter; a methods sentence.
- Initial fixation policy (Analysis field): "Keep all" / "Drop first fixation" / "Drop fixations
  within 1.5° of the cross before first saccade", with a count; applies to queries and references.
- Grid 64×48 on the image frame → cell 16 px = 0.46°. Show cell size next to Scales; warn
  when σ < 2 cells (0.5° ≈ 1.1 cells) and when σ makes maps near-uniform (8° ≈ 280 px on a
  29°×22° image).
- 35 px/° is DECLARED, not calibrated; linear conversion; shown with viewing distance/screen
  size fields in Data.
- Display kinds: Image · Blank · Blank + fixation cross · Cue · Unknown · Missing asset (hatched).
  Retrieval here = "Blank + fixation cross". Remembered-image underlay off by default and, when on,
  labelled "Reference image — not displayed during this trial".
- Recognition preset: lures/novel probes get "No corresponding study trial (by design)", a
  category separate from data-error "no match", in every count strip.
- Duplicate references: eyes4s preflight reports DuplicateTrial as a Warning; ByLeft reduction
  would AVERAGE two matched pairs. A "Studio check" (labelled as such, not eyes4s) blocks the run:
  "Matched cardinality ≠ 1 for 5 queries — choose occurrence".
- Exact eligible counts exist only after paging the design (PairPage.Done): show "counting…" with
  a progress state until then; before paging show only the candidate pair count.
- Identity: show "input digest sha256:9f2c…e41 · plan rev 5", never an invented fingerprint.
- Reporting: participant means, equal weight; per-group n; paired n; the unit is the query trial.
- Say "record" (fixations.csv record 7,214), not "row". Show raw and transformed coordinates.
- Import requires Ordinal and Sample-count roles; time units are DECLARED (ms), never inferred.

## 10. Keyboard and accessibility
Each plot/trial view is ONE focusable node with a roving cursor (arrow = nearest mark in that
direction via the picking plan; Enter = select → selection bus; Esc clear; Tab leaves). Show a
focused mark with a 2px accent ring. F6 cycles panes; ⌘⇧↩ maximizes the focused group. Every
plot has a synced Table tab.
