What Eyes Studio will ask you
It proposes an answer to each question, and you confirm it. Nothing that changes the science is guessed silently.
  1. 1Column rolesParticipant, phase, trial, x, y, onset, duration, plus the fixation ordinal and sample count.
  2. 2Time unitsDeclared by you, never inferred from the values.
  3. 3Screen frame and image placementOrigin, y direction, screen size, and where each image sat on the screen.
  4. 4Pixels per degreeDeclared directly, or derived from viewing distance and screen size. Shown as “declared · not calibrated”.
  5. 5Trial identityWhich columns make a trial unique, including repeated presentations.
Then you review admission: which trials are admitted, which are set aside, and why.Dataset · re-admitChanging these answers later creates a new dataset revision, pending admission.
