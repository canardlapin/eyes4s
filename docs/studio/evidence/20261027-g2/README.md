# G2 production qualification

The aggregate receipts in [qualification.json](qualification.json) and
[reference.json](reference.json) cover an owner-permitted processed fixation study
through the public API and the ordinary Eyes Studio production host. Private
records, subject/item/trial identifiers, screenshots, native projects and numerical
requests are excluded from Git.

The study has 103 participants, 509,182 fixation records and 60,922 observed trials.
Twenty-one complete-participant projects preserve every original record/column and
all within-participant comparison pools. Every project uses three separate JVMs:
API, production import/run/save/export/close, and fresh-process reopen/export/close.
The reopened project must use its saved reporting specification and figure. Both
export bundles receive independent CSV checks; all six files must reproduce byte
for byte. Every query-table cell is read from an actual rendered cell node.

All final map/failure objects and merged query objects must equal the independently
checked full-cohort API output. Both density implementations have independent
oracles, and both scorers are checked on identical arrays. The native estimators
remain different at this coarse grid; the largest staged discrepancy is dominated
by fixation binning. Neither package is treated as an unquestionable reference.

Actual summaries, query/reference maps in both themes, figures and fresh-process
redraws use production Intaglio. The receipt identifies the reviewed examples by
hash; machine screenshot coverage does not imply manual review of every image.
The restricted owner dashboard carries reviewed screenshots and aggregate progress.
Raw-record views and native projects remain local.

This qualifies exploratory pixel-space software behavior. Unknown display placement,
physical calibration, exported timing origin and endpoint convention remain unknown.
The saved run explicitly declares its virtual angular adapter. No biological effect,
temporal interpretation, calibrated-angle result or manuscript replication is claimed.
The observed-only inventory cannot establish absent planned trials.

A single full-cohort native archive exceeds existing limits. Those refusals and
performance traces are retained; `g2-archive-scaling` stays open and no budget was
raised. The large-origin unknown-extent timeline viewport/playhead has a separate open usability follow-up, `g2-timeline-coverage`; raw clocks must not be rewritten. Physical Retina/VoiceOver, researcher usability, clean-machine distribution,
public signing and Maven Central publication remain separate acceptance items.

Generic opt-in drivers live in [tools/private-fixtures](../../../../tools/private-fixtures/README.md).
They refuse private input inside any Git checkout and refuse CI. To replay archived
private fixtures, first copy them to a new external private directory, retain their
hash manifest, and build an exclusively owned checkout before freezing its classes.
All failed attempts and the numerical protocol are preserved with the ignored
private archive; an interrupted or failed qualification is never a passing receipt.
