# eyes4s-kernel

Geometry, time, trajectories, measures, grids, surfaces, regions, machines.

This module contains NO ocular vocabulary and must not depend on `eyes4s-core`;
`checkKernelPurity` enforces it. That boundary is what keeps a general
`trace4s` extractable later at no present cost.

Its only external dependency is cats-core.
