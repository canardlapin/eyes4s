# Python conformance fixtures

The normal `sbt` test suite does not install or invoke Python. It consumes
checked-in Scala fixtures generated by a pinned Python reference package.

Regenerate the MultiMatch fixtures with:

```sh
uv run tools/python-conformance/generate_multimatch_fixtures.py
```

Check that the committed fixture still matches the pinned oracle without
rewriting it:

```sh
uv run tools/python-conformance/generate_multimatch_fixtures.py --check
```

The generator calls `multimatch_gaze.docomparison` with `grouping=False`.
Its PEP 723 metadata pins Python and every package in the reference
environment. Update those pins deliberately; an oracle upgrade is a reviewable
change to the expected results.
